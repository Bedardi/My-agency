MISTAHUB AGENCY — CLOUDFLARE PAGES STATIC SITE

Deploy:
1. Extract this ZIP.
2. Upload the folder contents to your GitHub repository (keep index.html at the root).
3. Connect the repository to Cloudflare Pages.
4. Framework preset: None.
5. Build command: leave empty.
6. Build output directory: / (or the repository root, depending on the Pages setup).
7. Add agency.mistahub.in as a custom domain in Cloudflare Pages.

Included:
- Responsive static HTML pages
- Shared CSS and JavaScript in /assets
- Extensionless route rewrites in _redirects
- Security headers in _headers
- robots.txt and sitemap.xml
- 404 page and web manifest
